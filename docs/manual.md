# ScenarioWriterCafe 操作マニュアル（脚本家向け）

ScenarioWriterCafe は、舞台や映像の脚本を Web ブラウザで書くためのエディタです。
このマニュアルは、脚本を書く人が日常的に使う操作をまとめたものです。設置やサーバの話は [README](../README.md) にあります。

ScenarioWriterCafe には、ひとりで使う **標準版** と、仲間を招いて一緒に作る **コラボレーション版** があります。このマニュアルは両方に共通で、コラボレーション版だけにある機能には **【コラボ版】** と付けています。標準版を使っている人は、その項目を飛ばして読んでください。

---

## 1. インストール（設置する人向け）

インストール時に登録するユーザーは 1 人です。標準版はその 1 人が使います。コラボレーション版では、その人がプロデューサーになり、仲間はプロデューサーが発行する招待 URL からアカウントを作ります（11.5 章）。読んでもらうだけなら、どちらの版でも「劇団員プレビュー」（第 11 章）が使えます。

### 1.1 動作環境

| 項目 | 内容 |
|---|---|
| PHP | 7.4 以上（8.x 推奨）。レンタルサーバの標準的な PHP で動きます |
| データベース | 標準は **SQLite**（PHP に同梱。DB サーバ不要）。MySQL / MariaDB も選べます。ひとりで使うなら SQLite で十分です。【コラボ版】でも劇団の数人が同時に書く規模なら SQLite で十分です。数十人が常時書き込むなら MySQL を選んでください |
| Web サーバ | Apache（`.htaccess` がそのまま効きます）。nginx 等では `sw_config/` への直接アクセスを拒否する設定を別途入れてください |
| ブラウザ | 執筆はパソコンのブラウザ、プレビューはスマホでも読めます |

### 1.2 ダウンロードして FTP でアップする

1. GitHub の [Releases](https://github.com/ICTCacao/ScenarioWriterCafe/releases) から zip をダウンロードし、展開します。
2. 展開した `ScenarioWriterCafe/` フォルダの**中身**を、FTP ソフトでサーバの公開ディレクトリ（例: `public_html/`）へアップロードします。サブディレクトリ（例: `public_html/scw/`）に置いても動きます。転送モードは「自動」か「バイナリ」にしてください。
3. 次のフォルダに書き込み権限が必要です。多くのレンタルサーバでは既定のままで足ります（ディレクトリ 705、ファイル 604 など）。777 にする必要はありません。
   - `sw_config/` … 設定ファイルと SQLite のデータベースが作られます
   - `tmp/` … ダウンロード用の一時ファイル
   - `img/thumb/` … 作品画像

### 1.3 初回起動（初期設定）

![初期設定画面](img/setup.png)

1. ブラウザで `index.php` を開きます（例: `https://あなたのドメイン/scw/index.php`）。データベースが未設定なので、自動的に**初期設定画面**が開きます。ログイン画面の URL を直接開いても、未設定なら初期設定へ誘導されます。
2. 「データベース種別」は **SQLite（ファイル・標準）** が選ばれています。そのままで構いません。「接続テスト」は押さなくても大丈夫です（押すと「SQLite は使えます。DB ファイルはインストールで作成されます」と出ます）。
3. ログインに使う**メールアドレス**と**パスワード**を入力し、**インストール**を押します。テーブルとあなたのユーザーが作られ、`sw_config/swdata.sqlite`（データベース）と `sw_config/swDbSetting.php`（設定）が保存されます。
4. ログイン画面に移ります。以後、`index.php` を開くと直接ログイン画面になります。

**SQLite か MySQL か** … ひとりで使うなら SQLite で十分です。【コラボ版】でも劇団の数人が同時に書く規模なら SQLite で十分です（同時書き込みは自動で待ち合わせます）。数十人が常時書き込むなら MySQL を選んでください。MySQL を使いたいときは、サーバーパネルでデータベースとユーザーを作ってから、種別で「MySQL / MariaDB」を選び、ホスト名・DB 名・ユーザー名・パスワードを入れてインストールします。

### 1.4 一定のセキュリティをかける

| やること | 方法 |
|---|---|
| 検索ロボットに載せない | 同梱の `robots.txt`（`Disallow: /`）がサイト直下にあれば効きます。サブディレクトリに置いた場合は、サイト直下の `robots.txt` に `Disallow: /scw/` のように追記してください。ログイン画面・初期設定・プレビューには `noindex` も入れてあります |
| 初期設定画面を閉じる | 設定が終わったら `swSetup.php` を**削除**するか、名前を変えます。誰でも開ける画面なので、そのままにしないでください |
| 設定と DB を隠す | `sw_config/` は同梱の `.htaccess` で Web から拒否されます。ブラウザで `https://…/sw_config/swdata.sqlite` を開いて **403** になることを一度確認してください |
| HTTPS にする | レンタルサーバの無料 SSL を有効にし、`https://` で使います。パスワードやプレビュー URL が暗号化されます |
| 置き場所を推測されにくく | `scw/` のような短い名前より、`scw-2026-abc/` のように推測しにくいサブディレクトリ名にすると、URL を知らない人が辿り着きにくくなります |
| サイト全体に鍵をかける | Basic 認証（`.htaccess` + `.htpasswd`）で全体を守る方法もあります。ただし劇団員プレビューの URL も認証が必要になるので、プレビューを使う場合は `swPreview.php` だけ除外してください（下の例） |
| パスワードとバックアップ | 推測されにくいパスワードにし、`sw_config/swdata.sqlite` を定期的にダウンロードして控えます |

Basic 認証で `swPreview.php` だけ除外する `.htaccess` の例:

```apache
AuthType Basic
AuthName "ScenarioWriterCafe"
AuthUserFile /home/あなた/.htpasswd
Require valid-user
<Files "swPreview.php">
  Require all granted
</Files>
```

### 1.5 ローカルで動かす（動作環境の整備）

手元のパソコンでも同じものが動きます。試し書きや、サーバに上げる前の確認に使えます。

**PHP だけで動かす（いちばん簡単）**
PHP が入っていれば、展開したフォルダで次を実行し、ブラウザで `http://127.0.0.1:8080/index.php` を開きます。Mac は Homebrew の `brew install php`、Windows は php.net の zip を展開して PATH を通します。

```bash
cd ScenarioWriterCafe
php -S 127.0.0.1:8080
```

この方法では `.htaccess` が効かないので `sw_config/` は保護されませんが、自分のパソコンの中だけなら問題ありません。

**MAMP（Mac / Windows）**
`MAMP/htdocs/` の中に `ScenarioWriterCafe/` フォルダを置き、MAMP を起動して `http://localhost:8888/ScenarioWriterCafe/` を開きます。MAMP の設定で PHP を 7.4 以上にしてください。MySQL を使う場合は phpMyAdmin でデータベースを作ってから、初期設定で「MySQL / MariaDB」を選び、ホスト名 `localhost`、ユーザー名 `root`、パスワード `root`（MAMP の既定）を入れます。

**XAMPP（Windows / Mac / Linux）**
`xampp/htdocs/` の中に `ScenarioWriterCafe/` フォルダを置き、XAMPP コントロールパネルで Apache を起動して `http://localhost/ScenarioWriterCafe/` を開きます。Apache なので `.htaccess` も効きます。MySQL を使う場合は phpMyAdmin でデータベースを作り、ユーザー名 `root`、パスワードは空（XAMPP の既定）です。

**ローカルからサーバへ引っ越す**
SQLite なら、ローカルの `sw_config/swdata.sqlite` と `img/thumb/` の画像をサーバの同じ場所にアップロードするだけで、書いた作品ごと移せます（サーバ側で初期設定を済ませてから上書きしてください）。

## 2. 全体の流れ

1. **ログイン**する
2. **新規シナリオ**でタイトルと場面の数を決める（または **シナリオ選択**で既存の作品を開く）
3. **登場人物設定**・**場面設定**で人物と場面を整える
4. **シナリオ編集**で台詞とト書を書く
5. **劇団員プレビュー**で URL を発行して仲間に読んでもらう、または **ダウンロード**で台本ファイルにする

画面の左上にある **Scenario Edit Menu** から、いつでも各画面へ移動できます。

## 6. シナリオ編集（台詞を書く）

![シナリオ編集](img/edit.png)

いちばん使う画面です。

### 画面の見方

- **左上の選択欄**（例「冒頭」）… いま表示している場面。ここで場面を切り替えます。
- **各行** … 左から「並べ替えの取っ手 ⠿」「↑↓」「登場人物名（またはスタイル名）」「本文」。
- 行の下の**灰色のバー**にマウスを乗せると「＋ この下に追加」が出ます。
- **右上の検索** … 作品全体の台詞から言葉を探します。結果から本文をその場で直せます。

### 本文をその場で直す（いちばん速い方法）

本文の文字をクリックすると、その場が入力欄に変わります。

- 入力欄の外をクリックすると **自動で保存** されます
- **Ctrl + Enter**（Mac は Cmd + Enter）で確定
- **Esc** で取り消し

### 種別や登場人物ごと直す（編集フォーム）

![編集フォーム](img/edit_form.png)

行の<strong>登場人物名（または「編集」の文字）</strong>をクリックすると編集フォームが開きます。

| 欄 | 内容 |
|---|---|
| 左の選択（セリフ / ト書 / 歌詞 …） | 行の**種別**。色や字下げはオプション設定のスタイルに従います |
| 右の選択（登場人物） | 台詞を言う人。ト書など人物が要らない種別では空のままで構いません |
| 本文 | 改行もそのまま残ります |

**保存** で確定、**削除** でその行を消します。左上の ✕ でフォームを閉じます。

### 行を追加する

![行の追加](img/edit_insert.png)

追加したい場所のすぐ上の行の、下にある灰色のバーをクリックすると、その位置に空のフォームが開きます。
種別と登場人物を選び本文を書いて **保存** します。

### 並べ替える

- 行の **↑ ↓** で 1 つずつ動かします
- 左端の **⠿** をドラッグすると、まとめて好きな位置へ動かせます

### 別の場面へ移す・別の場面を書く

左上の場面の選択欄で切り替えます。場面そのものの追加や名前の変更は **場面設定** で行います。

## 10. シナリオ情報

![シナリオ情報](img/info.png)

タイトル・サブタイトル・作者名・分類・メモを直し、上のバーの **シナリオ情報更新** を押します。

## 11. 劇団員プレビュー（仲間に読んでもらう）

「シナリオ情報」画面の下にあります。

1. **プレビューを公開する** を押すと URL が出ます。
2. **コピー** で URL を控え、メールや LINE などで劇団員に送ります。**開く** で自分でも確認できます。
3. 読ませたくなくなったら **公開を停止する**。同じ URL は開けなくなります（再公開すると同じ URL が復活）。
4. URL が広まりすぎたときは **URLを作り直す**。以前の URL は無効になり、新しい URL だけが有効です。

URL を知っている人は誰でも読めます（ログインは不要で、編集はできません）。台詞を直すとプレビューにもすぐ反映されます。

### 読む側の画面

| 横書き | 縦書き |
|---|---|
| ![横書き](img/preview_yoko.png) | ![縦書き](img/preview_tate.png) |

スマホで読む前提の画面です。上のバーで次の操作ができます。

- **場面** … 場面の一覧から目的の場面へ飛ぶ
- **A- / A+** … 文字の大きさ
- **縦書き / 横書き** … 切り替え。縦書きは右から左へ横にスクロールして読みます

設定はその端末のブラウザに記憶されます。

## 11.5 【コラボ版】コラボ制作（仲間と一緒に作る）

この章はコラボレーション版だけの機能です。標準版にはありません。コラボレーション版では、作品ごとに仲間を招いて一緒に作れます。作品を作った人が **プロデューサー** で、作品を開いてメニューの **コラボ制作** を選びます（このメニューはプロデューサーにだけ出ます）。

### 役割と権限

役割名はプロデューサーが自由に決めます。初期値は **ライター**（編集できる）と **閲覧者**（閲覧のみ）で、演出・音響・キャストなど劇団の呼び方で足せます。各役割には次の 2 段階の権限のどちらかを付けます。

| 権限 | できること |
|---|---|
| **プロデューサー** | 作品を作った人。すべての操作（削除・複写・役割の定義・メンバー管理・プレビュー公開）ができます |
| **編集できる** | 台詞・場面・登場人物・シノプシス・シナリオ情報を編集できます。削除・複写・メンバー管理はできません |
| **閲覧のみ** | 読む・ダウンロードだけ。シナリオ選択のカードを押すと「シナリオを読む」が開きます |

上のバーの作品名の横に、自分の役割名のバッジが出ます（コラボレーション版のみ）。

### 仲間を招く（プロデューサー）

1. **役割の定義** … 必要なら役割名と権限を入れて **役割を追加**。不要な役割は × で消せます（既にその役割の人はそのまま残ります）。
2. **メンバーを追加** … 相手が既にこのサイトにアカウントを持っているなら、メールアドレスと役割を選んで **追加する**。
3. **招待 URL** … まだアカウントが無い人には、役割と有効期限（7 日 / 30 日 / 無期限）を選んで **招待 URL を発行** し、**コピー** して渡します。同じ URL を複数の人に渡せます。不要になったら **無効にする**。
4. 受け取った人は URL を開き、**ログインして参加する**（登録済み）か **アカウントを作って参加する**（はじめて）を押します。参加するとシナリオ選択にその作品が出ます。

メンバー一覧では役割の変更と **外す** ができます。

### 一緒に作っているとき

- **在席** … 同じ作品を開いている人と、その人が見ている画面が上のバーに出ます（約 20 秒ごとに更新）。
- **他の人の更新** … 誰かが直すと、上に黄色い通知バーが出ます。書いている途中の入力を壊さないよう自動では読み直さないので、区切りの良いところで **再読み込み** を押してください。シナリオ編集では今の場面だけ読み直します。
- **最近の更新** … コラボ制作画面の下に、誰がいつ何を直したか（場面名つき）が並びます。
- 同じ台詞を同時に直すと後から保存した方が残ります。台詞単位で分担するか、通知が出たら読み直してから続けるのが安全です。

## 14. オプション設定（見た目と書式）

![オプション設定](img/option.png)

### USER OPTION 設定

| 項目 | 内容 |
|---|---|
| シナリオヘッダ部文字数 | テキスト出力で、登場人物名の欄に使う文字数 |
| シナリオボディ部文字数 | テキスト出力で、本文 1 行の文字数 |
| 台詞を「」で囲む | チェックを外すと、台詞に「」を付けなくなります（画面・プレビュー・出力すべて） |

### USER STYLE 設定

行の**種別**ごとの見た目です。セリフ、ト書、歌詞、ナレーション、モノローグ、テロップ、演技指示、音響指示、照明指示、フェードイン…といった種別が最初から入っています。

| 項目 | 内容 |
|---|---|
| 並び順 | 編集フォームの種別選択に出る順 |
| スタイル名 | 種別の名前 |
| フォントサイズ / フォント色 | 画面とプレビューでの見た目 |
| 字下げ数 | 本文の頭を何文字下げるか |
| 省略文字 | 登場人物名の代わり、または後ろに付く記号（例: NA、M、SE、(F.I)） |
| 表示の仕方 | 「登場人物名を出す / 出さない」と「台詞を「」で囲む / 囲まない」の組み合わせ |

上のバーの **USER STYLE追加** で自分用の種別を増やせます。一覧の行をクリックすると編集や削除ができます。

## 16. 困ったとき

| 症状 | 対処 |
|---|---|
| 「ログインしてください」と出てログイン画面に戻る | 長時間操作しなかったか、別のタブでログアウトしています。ログインし直してください |
| 保存したはずの台詞が消えた | 入力欄の外をクリックする前にページを閉じると保存されません。Ctrl + Enter で確定してから移動してください |
| 劇団員が URL を開くと「公開されていません」と出る | 公開を停止しているか、URL を作り直した後の古い URL です。シナリオ情報で現在の URL を確認してください |
| Word ファイルの表紙が空 | ダウンロード画面の作者名・日付などを埋めてからボタンを押してください |
| 作品を消してしまった | 元に戻す機能はありません。設置者にバックアップ（SQLite なら `sw_config/swdata.sqlite` のコピー）から戻せないか相談してください |

バックアップは、こまめに **ダウンロード（テキスト）** で手元に控えを残しておくのが確実です。
