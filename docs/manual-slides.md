# ScenarioWriterCafe
## 操作マニュアル（脚本家向け）

舞台・映像の脚本を Web ブラウザで書くエディタ

<span class="small">2026-09 版　標準版・コラボレーション版 共通（コラボ版だけの機能には【コラボ版】）</span>

---

## 全体の流れ

1. **ログイン**する
2. **新規シナリオ**でタイトルと場面の数を決める（既存の作品は**シナリオ選択**で開く）
3. **登場人物設定**・**場面設定**で人物と場面を整える
4. **シナリオ編集**で台詞とト書を書く
5. **劇団員プレビュー**で URL を発行して仲間に読んでもらう、または**ダウンロード**で台本ファイルにする

画面左上の **Scenario Edit Menu** から、いつでも各画面へ移動できます。

# インストール（設置する人向け）
サーバに置く / ローカルで動かす / 最初の起動 / 守り方

---

## 動作環境と、ひとつ大事な注意

| 項目 | 内容 |
|---|---|
| PHP | 7.4 以上（8.x 推奨）。レンタルサーバの標準的な PHP で可 |
| データベース | 標準は **SQLite**（PHP に同梱、DB サーバ不要）。MySQL / MariaDB も可。ひとりなら SQLite で十分。【コラボ版】数人同時でも SQLite で十分、数十人が常時書くなら MySQL |
| Web サーバ | Apache（`.htaccess` が効く）。nginx 等は `sw_config/` の拒否設定を別途 |
| ブラウザ | 執筆はパソコン、プレビューはスマホでも |

**標準版はひとりの脚本家が使う前提です。** ログインできるのはインストール時に登録した 1 人だけ。
仲間に読んでもらうには「劇団員プレビュー」を使います。
**【コラボ版】** はその 1 人がプロデューサーになり、招待 URL で仲間を増やして一緒に作ります。

---

## ダウンロードして FTP でアップする

1. GitHub の **Releases** から zip をダウンロードして展開
   https://github.com/ICTCacao/ScenarioWriterCafe/releases
2. `ScenarioWriterCafe/` フォルダの**中身**を、FTP ソフトで公開ディレクトリへ
   （例: `public_html/` または `public_html/scw/`）。転送モードは「自動」か「バイナリ」
3. 書き込み権限が必要なフォルダ（多くのレンタルサーバは既定のままで OK。777 は不要）
   - `sw_config/` … 設定と SQLite のデータベース
   - `tmp/` … ダウンロード用の一時ファイル
   - `img/thumb/` … 作品画像

---

## 初回起動（初期設定）

![bg right:50% fit](img/setup.png)

1. ブラウザで `index.php` を開く → 未設定なので自動で**初期設定画面**（ログイン画面を直接開いても誘導されます）
2. 種別は **SQLite（標準）** のまま。接続テストは押さなくて OK
3. ログイン用の**メールアドレス**と**パスワード**を入れて **インストール**
   → `sw_config/swdata.sqlite` と `swDbSetting.php` が作られる
4. ログイン画面へ。以後 `index.php` は直接ログイン画面に

MySQL を使うなら、先に DB を作ってから種別で選び、接続情報を入力

---

## 一定のセキュリティをかける

| やること | 方法 |
|---|---|
| 検索ロボットに載せない | 同梱 `robots.txt`（`Disallow: /`）。サブディレクトリ設置なら直下の robots.txt に `Disallow: /scw/` を追記。ログイン・設定・プレビューは `noindex` 済み |
| 初期設定画面を閉じる | 設定後に `swSetup.php` を**削除**（誰でも開ける画面） |
| 設定と DB を隠す | `sw_config/` は `.htaccess` で拒否。`…/sw_config/swdata.sqlite` が **403** になるか一度確認 |
| HTTPS | 無料 SSL を有効にし `https://` で使う |
| 置き場所 | `scw-2026-abc/` のような推測しにくいサブディレクトリ名に |
| 全体に鍵 | Basic 認証も可。ただし `swPreview.php` は除外しないと劇団員が読めない |
| 控え | 推測されにくいパスワード。`sw_config/swdata.sqlite` を定期的にダウンロード |

## ローカルで動かす（1）PHP だけで動かす

手元のパソコンでも同じものが動きます。試し書きや、サーバに上げる前の確認に。

PHP が入っていれば、展開したフォルダで次を実行してブラウザで開くだけです。

```bash
cd ScenarioWriterCafe
php -S 127.0.0.1:8080
```

→ http://127.0.0.1:8080/index.php

- Mac: `brew install php`　／　Windows: php.net の zip を展開して PATH を通す
- この方法では `.htaccess` が効かず `sw_config/` は保護されませんが、自分のパソコンの中だけなら問題ありません

---

## ローカルで動かす（2）MAMP / XAMPP

| | MAMP（Mac / Windows） | XAMPP（Windows / Mac / Linux） |
|---|---|---|
| 置き場所 | `MAMP/htdocs/ScenarioWriterCafe/` | `xampp/htdocs/ScenarioWriterCafe/` |
| 開く URL | http://localhost:8888/ScenarioWriterCafe/ | http://localhost/ScenarioWriterCafe/ |
| 準備 | 設定で PHP を 7.4 以上に | コントロールパネルで Apache を起動 |
| MySQL を使う場合 | phpMyAdmin で DB を作成。ユーザー `root` / パスワード `root` | phpMyAdmin で DB を作成。ユーザー `root` / パスワードは空 |

初回起動の手順はサーバと同じです（`index.php` → 初期設定 → SQLite のままインストール）。

**ローカルからサーバへ引っ越す** … SQLite なら `sw_config/swdata.sqlite` と `img/thumb/` の画像をサーバの同じ場所へアップロードするだけで、書いた作品ごと移せます（サーバ側で初期設定を済ませてから上書き）。

# シナリオ編集
いちばん使う画面。台詞とト書を書く

---

## シナリオ編集：画面の見方

![bg right:55% fit](img/edit.png)

- **左上の選択欄**（例「冒頭」）… 表示中の場面。ここで切り替え
- **各行** … 左から「取っ手 ⠿」「↑↓」「登場人物名」「本文」
- 行の下の**灰色バー**に乗せると「＋ この下に追加」
- **右上の検索** … 作品全体の台詞から言葉を探す

---

## シナリオ編集：本文をその場で直す

![bg right:50% fit](img/edit.png)

本文の文字をクリックすると、その場が入力欄に変わります。

- 入力欄の外をクリック → **自動で保存**
- <span class="kbd">Ctrl</span> + <span class="kbd">Enter</span>（Mac は Cmd + Enter）→ 確定
- <span class="kbd">Esc</span> → 取り消し

いちばん速い直し方です。種別や登場人物を変えたいときは次の編集フォームを使います。

---

## シナリオ編集：編集フォーム

![bg right:55% fit](img/edit_form.png)

行の<strong>登場人物名（または「編集」）</strong>をクリックすると開きます。

| 欄 | 内容 |
|---|---|
| 左の選択 | 行の**種別**（セリフ / ト書 / 歌詞 …） |
| 右の選択 | 台詞を言う**登場人物** |
| 本文 | 改行もそのまま残る |

**保存** で確定、**削除** で行を消す、✕ で閉じる

---

## シナリオ編集：行の追加と並べ替え

![bg right:55% fit](img/edit_insert.png)

### 追加
すぐ上の行の下にある灰色バーをクリック → その位置に空のフォーム → 種別・人物・本文を入れて **保存**

### 並べ替え
- **↑ ↓** で 1 つずつ
- 左端の **⠿** をドラッグして好きな位置へ

---

## 場面設定

![bg right:50% fit](img/scene.png)

上のバーの **場面追加** でフォームが開きます。

| 項目 | 内容 |
|---|---|
| 並び順 | 小さい順。↑↓ でも変更可 |
| 場面名 | 台本の「柱」 |
| 場面説明 | 場所や時間。台本にも出る |
| 時間（分・秒） | 目安の上演時間。合計が一覧上部に |
| 一括登録 | 「○幕 ○場」の数でまとめて作成 |

一覧の場面名をクリック → 編集・削除

---

## 登場人物設定

![bg right:50% fit](img/character.png)

上のバーの **登場人物追加** で人物を足します。

| 項目 | 内容 |
|---|---|
| 並び順 | 一覧と人物表の順 |
| 登場人物名 | 台詞の頭に出る名前 |
| 人物設定 | 年齢・性格など。人物表とプレビューに出る |

一覧の名前をクリック → 編集・削除
台詞で使っている人物を削除すると、その台詞は名前なしになります

---

## シノプシス

![bg right:55% fit](img/synopsis.png)

あらすじ・梗概を書いて、上のバーの **シノプシス保存**。

ダウンロードした台本（テキスト / Word）の冒頭と、劇団員プレビューに入ります。

---

## シナリオ情報

![bg right:50% fit](img/info.png)

タイトル・サブタイトル・作者名・分類・メモを直して **シナリオ情報更新**。

- **作品画像** … ドラッグ＆ドロップで登録。選択画面のカードに出る
- **シナリオ複写** … 同じ内容をもう 1 つ作る。改稿前の控えに
- **シナリオ削除** … 場面・人物・台詞ごと消える。**元に戻せない**ので先に複写かダウンロードを

---

## 劇団員プレビュー：公開する

![bg right:50% fit](img/info.png)

「シナリオ情報」画面の下にあります。

1. **プレビューを公開する** → URL が出る
2. **コピー** して劇団員に送る。**開く** で自分でも確認
3. **公開を停止する** → 同じ URL は開けなくなる（再公開で復活）
4. **URLを作り直す** → 古い URL は無効、新しい URL だけ有効

URL を知っている人は誰でも読めます（ログイン不要・編集不可）。台詞を直すとすぐ反映。

---

## 劇団員プレビュー：読む側の画面

![bg right:45% fit](img/preview_tate.png)

スマホで読む前提の画面です。

- **場面** … 一覧から目的の場面へ
- **A- / A+** … 文字の大きさ
- **縦書き / 横書き** … 切り替え。縦書きは右から左へ横スクロール

設定はその端末のブラウザに記憶されます。

---

## 【コラボ版】コラボ制作：役割と権限

作品を作った人が **プロデューサー**。メニューの **コラボ制作** はプロデューサーにだけ出ます。

| 権限 | できること |
|---|---|
| **プロデューサー** | すべて（削除・複写・役割の定義・メンバー管理・プレビュー公開） |
| **編集できる** | 台詞・場面・登場人物・シノプシス・シナリオ情報の編集、読む、ダウンロード |
| **閲覧のみ** | 読む・ダウンロードだけ。カードを押すと「シナリオを読む」が開く |

役割名は自由（初期値: **ライター**=編集できる、**閲覧者**=閲覧のみ）。演出・音響・キャストなど劇団の呼び方で足し、各役割に上の 2 段階のどちらかを付けます。

---

## 【コラボ版】コラボ制作：仲間を招く

1. **役割の定義** … 役割名と権限を入れて **役割を追加**（× で削除。既にその役割の人はそのまま）
2. **メンバーを追加** … 登録済みの人はメールアドレスと役割で **追加する**
3. **招待 URL** … まだアカウントが無い人には役割と期限（7 日 / 30 日 / 無期限）で **発行** → **コピー** して渡す。同じ URL を複数人に渡せる。不要なら **無効にする**
4. 受け取った人は **ログインして参加** か **アカウントを作って参加**。参加するとシナリオ選択にその作品が出る

メンバー一覧で役割の変更と **外す** ができます。

---

## 【コラボ版】一緒に作っているとき

- **在席** … 同じ作品を開いている人と見ている画面が上のバーに出る（約 20 秒ごと）
- **他の人の更新** … 黄色い通知バーが出る。自動では読み直さないので、区切りで **再読み込み**。シナリオ編集は今の場面だけ読み直す
- **最近の更新** … コラボ制作画面の下に、誰がいつ何を直したか（場面名つき）
- 同じ台詞を同時に直すと後から保存した方が残る。台詞単位で分担するか、通知が出たら読み直してから続ける

左の場面名をクリックするとその場面へ。書きながら流れを確かめるときに。

## ダウンロード（台本ファイルにする）

![bg right:50% fit](img/download.png)

| ボタン | 内容 |
|---|---|
| **テキスト.txt** | 文字だけ。字下げは全角空白。文字数はオプション設定に従う。文字コード / 改行コードは上で選ぶ |
| **A4縦 縦書き.docx** | Word 用、縦書き台本 |
| **A4縦 横書き / A4横 縦書き.docx** | deerstudio 配布テンプレートを使う。表紙の作者名・日付などを埋めてから押す |

Word 2007 以降、または互換ソフトで開けます

---

## オプション設定（見た目と書式）

![bg right:50% fit](img/option.png)

### USER OPTION
- **ヘッダ部 / ボディ部文字数** … テキスト出力の名前欄と本文 1 行の文字数
- **台詞を「」で囲む** … 外すと全画面・出力で「」なし

### USER STYLE（種別ごとの見た目）
並び順・スタイル名・フォントサイズ / 色・字下げ数・省略文字（NA, M, SE, (F.I) …）・名前の表示と「」の有無

**USER STYLE追加** で自分用の種別も作れます

---

## パスワード変更・ログアウト

![bg right:50% fit](img/password.png)

- メニューの **パスワード変更** … 登録名と新しいパスワードを設定
- 作業を終えるときはメニューの **ログアウト**。共用のパソコンでは特に忘れずに

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「ログインしてください」と出る | 長時間操作なし、または別タブでログアウト済み。ログインし直す |
| 台詞が保存されていない | 入力欄の外をクリックする前にページを閉じた。Ctrl + Enter で確定してから移動 |
| 劇団員が「公開されていません」と言う | 停止中か、作り直し前の古い URL。シナリオ情報で現在の URL を確認 |
| Word の表紙が空 | ダウンロード画面の作者名・日付などを埋めてから押す |
| 作品を消してしまった | 元に戻す機能なし。設置者にバックアップからの復元を相談 |

こまめに **ダウンロード（テキスト）** で手元に控えを残すのが確実です。
