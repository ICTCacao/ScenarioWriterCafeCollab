# ScenarioWriterCafe（コラボレーション版）

舞台・映像の脚本を Web ブラウザで書くための脚本エディタです。この「コラボレーション版」は、ひとり用の [ScenarioWriterCafe（標準版）](https://github.com/ICTCacao/ScenarioWriterCafe) に **複数人でのコラボ制作** を足した派生版です。リポジトリ: https://github.com/ICTCacao/ScenarioWriterCafeCollab
PHP と SQLite だけで動くので、レンタルサーバや手元の PC にフォルダを置くだけで始められます。

**脚本家向けの操作マニュアル → [docs/manual.md](docs/manual.md)**

## 特長

- **場面・登場人物・台詞** を分けて書き、並び替えや複写ができる
- 台詞をクリックしてその場で直す **インライン編集（自動保存）**
- **劇団員プレビュー** … 鍵付き URL を渡すだけで、ログインなしにスマホで読める（縦書き / 横書き切替）
- **コラボ制作** … 作品ごとにプロデューサーが役割（ライター・演出・キャストなど自由に定義。権限は「編集できる / 閲覧のみ」）を決めて仲間と一緒に作る。招待 URL でアカウント登録、在席表示と他の人の更新通知（20 秒ごとのポーリング。WebSocket 不要）
- **ダウンロード** … テキスト、Word（A4 縦書き / 横書き）、XML
- 台詞の色・字下げ・「」の付け方などを **スタイル設定** で自分好みに
- **SQLite（標準）** または **MySQL / MariaDB** を選べる。DB サーバ不要で動く
- 旧 CGI 版のデータ取り込みツール付き

## 必要なもの

- PHP 7.4 以上（8.x 推奨）。PDO の `sqlite` または `mysql` ドライバ（通常は同梱）
- データベースは、劇団の数人が同時に書く規模なら SQLite で十分です。数十人が常時書き込むなら MySQL を選んでください
- Apache なら `.htaccess` がそのまま効きます。nginx 等では `sw_config/` への直接アクセスを拒否する設定を別途入れてください

## インストール

1. このリポジトリの内容（または [Releases](../../releases) の zip）を Web 公開ディレクトリに置く。サブディレクトリでも可
2. `sw_config/` `tmp/` `img/thumb/` に書込権限を付ける（レンタルサーバの既定で足りることが多い）
3. ブラウザで `index.php` を開く → 初期設定画面
4. 「データベース種別」は標準で **SQLite** が選ばれています。メールアドレスとパスワードを入れて「インストール」
5. ログイン画面に移るので、登録した情報でログイン

設定後は `swSetup.php` を削除するか、アクセス制限してください。

手元で試すだけなら PHP の組み込みサーバでも動きます。

```bash
php -S 127.0.0.1:8080
# → http://127.0.0.1:8080/index.php
```

## コラボ制作

作品を作った人が **プロデューサー** です。作品を開いてメニューの **コラボ制作**（プロデューサーだけに出ます）で、役割の定義とメンバーを管理します。

| 権限 | できること |
|---|---|
| **プロデューサー** | すべて（削除・複写・役割の定義・メンバー管理・プレビュー公開を含む） |
| **編集できる** | 台詞・場面・登場人物・シノプシス・シナリオ情報の編集、読む、ダウンロード |
| **閲覧のみ** | 読む、ダウンロードだけ |

- **役割の定義** … 役割名は自由（初期値: ライター=編集できる、閲覧者=閲覧のみ）。演出・音響・キャストなど劇団の呼び方で足せます。各役割に上の 2 段階の権限を付けます
- **メンバーを追加** … 登録済みのユーザーをメールアドレスと役割で追加
- **招待 URL** … まだアカウントが無い人向け。`swInvite.php?k=…` を渡すと、その人はログインまたは新規登録してから参加します（新規登録はこの招待経由だけ）。期限（7 日 / 30 日 / 無期限）を選べ、いつでも無効にできます
- 同じ作品を開いている人は上のバーに **在席** として出ます。他の人が更新すると通知バーが出るので、**再読み込み** で最新にします（書いている途中の入力を壊さないよう、自動では読み直しません）
- コラボ制作画面の **最近の更新** で、誰がいつ何を直したかを確認できます

仕組みは `include/swCollab.php`（役割・メンバー・招待・履歴・在席）と `include/swCollabGuard.php`（各画面の権限チェック）にまとめています。表 `SW_SCENARIO_MEMBER` `SW_SCENARIO_INVITE` `SW_SCENARIO_ROLE` `SW_ACTIVITY` `SW_PRESENCE` は、既存の DB にも初回アクセス時に自動で作られます。

## 劇団員プレビュー

「シナリオ情報」画面の「劇団員プレビュー」で **公開する** を押すと、`swPreview.php?k=…` の URL が発行されます。
URL を知っている人だけが閲覧でき（編集不可）、**停止する** で無効になります。スマホ向けの画面で、縦書き / 横書きと文字サイズを切り替えられます。

## 旧 CGI 版からの移行

旧版のデータ一式（`Scenario_index.cgi` とシナリオごとのフォルダ）を `ScenarioFolder/` に置き、ログイン後に `swScenarioTrans.php` を開いて「取り込む」を押します。内容を確認してから実行され、SQLite / MySQL どちらでも動きます。

## バックアップ

SQLite の場合は `sw_config/swdata.sqlite`（あれば `-wal` `-shm` も）をコピーするだけです。

## ディレクトリ

| 場所 | 内容 |
|---|---|
| `sw_config/` | 設定とスキーマ。SQLite の DB ファイルもここ。Web からは `.htaccess` で拒否 |
| `include/` | 共通処理（DB 接続 `swDb.php`、プレビュー `swPreview.php`、コラボ制作 `swCollab.php` `swCollabGuard.php` など） |
| `class/` | テーブルごとのデータクラス |
| `ajax/` | 画面から呼ばれる処理 |
| `Scenario_Template/` | Word 出力のテンプレート |
